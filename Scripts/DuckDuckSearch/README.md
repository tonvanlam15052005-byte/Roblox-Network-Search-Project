How to use this .rbxm file [ENG]
1. Download the file:
- On the GitHub page, click on the file `DuckDuckSearch-Roblox-ENG.rbxm`.
- Click the "Download" button (or "Raw" → right-click → "Save link as") to save the file to your computer.
- Open Roblox Studio and open your project (game).
2. Import the file into Studio:
- Go to the "Home" tab on the toolbar.
- Find and click the "Toolbox" button.
- In the Toolbox window that appears, switch to the "Inventory" tab.
- In the top-right corner of the Toolbox window, click the upload arrow icon and select "From File...".
- Navigate to the `DuckDuckSearch-Roblox-ENG.rbxm` file you just downloaded and select it.
- The model file will appear in your Toolbox.
3. Add to the game:
- Drag and drop the model from the Toolbox into the "Workspace" or the 3D viewport in Studio.
- Follow the instructions inside the folder.

Cách sử dụng file .rbxm này [VIE]
1. Tải file về máy:
- Trên trang GitHub của bạn, bấm vào file DuckDuckSearch-Roblox-ENG.rbxm.
- Bấm nút "Download" (hoặc "Raw" → chuột phải → "Save link as") để lưu file về máy tính.
- Mở Roblox Studio và mở dự án (game) của bạn.
2. Import file vào Studio:
- Vào tab "Home" (Trang chủ) trên thanh công cụ.
- Tìm và bấm vào nút "Toolbox" (hộp công cụ).
- Trong cửa sổ Toolbox hiện ra, chuyển sang tab "Inventory" (Kho đồ) của bạn.
- Ở góc trên cùng bên phải của cửa sổ Toolbox, bấm vào biểu tượng mũi tên tải lên (Upload) và chọn "From File..." (Từ tệp...).
- Duyệt đến file DuckDuckSearch-Roblox-ENG.rbxm bạn vừa tải và chọn nó.
- File model sẽ xuất hiện trong Toolbox của bạn.
3. Đưa vào game:
- Kéo thả model từ Toolbox vào "Workspace" (Không gian làm việc) hoặc cửa sổ xem trước 3D trong Studio.
- Làm theo hướng dẫn của folder.
